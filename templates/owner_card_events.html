🎁 Cards Events

Drops aleatoires de cartes dans un salon. La premiere reaction sur le message gagne la carte. Configure par serveur (intervalle min-max + rareté minimum). Trigger manuel pour tester.

🧪 Trigger manuel (test)

🎯 Carte choisie : ✖ revenir à l'aléatoire
Si les salons ne s'affichent pas : clic sur 🔄 à côté du serveur dans les configs ci-dessous pour rafraîchir.

⚔️ Spawn boss de combat

🔁 Cercle des éléments
Chacun est fort (×1.25) contre le suivant et faible (×0.8) contre le précédent. Cycle : 🔆 Éclat → 🌊 Abysse → ⛓ Fracture → 🩸 Vif → 🕳 Néant → 🔆

🎡 Roue de la chance

Reset = chacun peut re-tourner immédiatement. Vider la liste = efface seulement le feed "en direct" (n'autorise pas de re-tourner).

🎲 Gestion des rolls

Reset = remet à zéro le cooldown de roll de tout le monde (chacun peut re-roll tout de suite). Give = offre N rolls bonus à tout le monde (non rechargeables, consommés avant les rolls normaux).

🧪 Tester sur un utilisateur

Cible un ID Discord (ex : ton compte test) pour vérifier reset/give avant de l'appliquer à tous.

⚙ Configuration globale des drops

Ces réglages s'appliquent à tous les serveurs ayant activé Cards Events. Le bot dropera une carte toutes les X minutes (intervalle aléatoire min-max), au-dessus de la rareté minimale. Le salon est choisi automatiquement par serveur (system channel ou premier salon où le bot peut écrire).
