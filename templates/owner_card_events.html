🎁 Cards Events

Drops aleatoires de cartes dans un salon. La premiere reaction sur le message gagne la carte. Configure par serveur (intervalle min-max + rareté minimum). Trigger manuel pour tester.

🧪 Trigger manuel (test)

Si les salons ne s'affichent pas : clic sur 🔄 à côté du serveur dans les configs ci-dessous pour rafraîchir.

🎲 Gestion des rolls

Reset = remet à zéro le cooldown de roll de tout le monde (chacun peut re-roll tout de suite). Give = offre N rolls bonus à tout le monde (non rechargeables, consommés avant les rolls normaux).

🧪 Tester sur un utilisateur

Cible un ID Discord (ex : ton compte test) pour vérifier reset/give avant de l'appliquer à tous.

⚙ Configurations par serveur

Active la box pour activer les drops automatiques sur ce serveur. Le bot dropera une carte aleatoire toutes les X minutes (intervalle aleatoire entre min et max).
